# League Music

Player web inspirado no universo de League of Legends, criado por **Ylgner Witoszynski Santana**.

O projeto reproduz clipes oficiais incorporados do YouTube e oferece uma biblioteca de faixas do universo League of Legends e K/DA.

## Recursos

- Reprodução, pausa, avanço e retorno de faixas
- Busca na playlist e filtro de favoritas
- Favoritos, volume, aleatório e repetição salvos no navegador
- Barra de progresso clicável
- Atalhos: `Espaço` (tocar/pausar), setas (trocar faixa), `M` (silenciar), `S` (aleatório) e `R` (repetição)
- Retomada da última faixa e posição de reprodução
- Painel lateral de playlist recolhível
- Layout responsivo e PWA instalável

## Tecnologias

- HTML, CSS e JavaScript
- YouTube IFrame Player API
- Service Worker e Web App Manifest

## Executar localmente

Abra o projeto por um servidor local para que a playlist e o player sejam carregados corretamente. Por exemplo, usando a extensão Live Server no VS Code.
